# Daji OS website

Static marketing site. No build step.

- Pages: `index.html`, `features.html`, `workflows.html`, `security.html`, `portal.html`, `404.html`.
- `config.js`: one line sets the address of the Daji OS application, used by the "Log in" and "Get started" buttons.
- `img/`: screenshots of the running software with synthetic demo data.
- `render.yaml`: Render static-site definition (publish directory is the repo root).
